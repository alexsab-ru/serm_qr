# Оценка сотрудников кассовой зоны — qr.aeroterms.ru

Дата: 2026-07-09. Статус: дизайн согласован.

## Задача

Таблица сотрудников (gid=55450114 той же Google-таблицы, уже прописана в
`employee_page` конфига `qr.aeroterms.ru.json`) должна обрабатываться, как
остальные: первая строка (русские подписи) отсекается, вторая становится
ключами, страницы открываются по `Path`, по `Code` — редирект на `URL`.
Отличие таблицы: нет колонок `Domain` и `utm_term`, колонка фото без ключа
(отбрасывается `removeEmptyFirstRowColumns`).

Страница сотрудника — не контакт-карточка, а форма оценки кассира.

## Изменения

### 1. `inc/functions.php` — толерантный `getDateFromSheet`

- Фильтр `Domain == $server_name` применять только если колонка `Domain`
  есть в строке ключей (`in_array('Domain', $col)`). Для таблиц с колонкой
  поведение не меняется.
- `utm_source`/`utm_term` в `mapLong` и `Photo` в обработке фото читать
  через `?? ''` — отсутствие колонок не роняет обработку.
- `getTheme`: `SuffixVCF` через `?? ''` (в таблице аэротерм колонки нет).
- Попутный фикс `checkUpdateParam`: голый `?updatetable` (без значения)
  снова запускает обновление таблицы сотрудников — раньше пустое значение
  игнорировалось и обновление срабатывало только при отсутствии
  JSON-кэша.

### 2. `inc/scripts/index_root.php` — выбор шаблона

В default-ветке (страница сотрудника по `Path`) вместо безусловного
`inc/theme_employee.php` подключать `inc/theme_employee_rate.php`, если в
конфиге сайта `"employee_theme": "rate"`. Ветки vcf/Code-редиректа не
трогаем.

### 3. Новый шаблон `inc/theme_employee_rate.php`

- head + header-3 (логотип «Аэротермы» из конфига)
- `inc/main/rate-employee.php` (форма)
- `inc/main/review/add-review-good.php` (скрытый блок внешних отзывов)
- messenger + social (как на текущих страницах)
- Без contact-card, vcf-кнопки, QR-блока, service-links.

### 4. Новый партиал `inc/main/rate-employee.php`

- H1 «Оцените работу сотрудников кассовой зоны», подзаголовок «Нам важно,
  чтобы каждый гость чувствовал заботу. Расскажите, как вас встретили на
  кассе». Тексты переопределяются конфигом `rate_employee.title/.subtitle`
  (опционально), по умолчанию — эти.
- Блок «👤 Кого оцениваем»:
  - «ФИО кассира» — readonly, `Surname + Name + Middle` из данных страницы,
    поле формы с русским именем (уходит в Telegram/gsheet как есть)
  - «Дата и время обслуживания» — `<input type="datetime-local">`,
    JS подставляет текущее время клиента, можно изменить пикером
- Блок «🏆 Общий балл за обслуживание», вопрос «Как вы оцените работу
  сотрудника кассовой зоны?»: 5 звёзд (стили `.star`/`.rating-stars`
  переиспользуются), оценка обязательна
- Блок «💬 Комментарий»: textarea «Что в работе кассира вам особенно
  понравилось? Что можно улучшить?» — виден всегда, НЕобязателен
  (имя поля НЕ `comment`, чтобы не сработала обязательная валидация
  mail.php)
- Чекбокс согласия на обработку ПД (mail.php требует `agree`)
- Кнопка «Отправить»

### 5. `inc/sites/qr.aeroterms.ru.json`

Добавить `"employee_theme": "rate"`.

### 6. `js/main.js`

- Клик по звезде: подсветка выбранных, установка глобальной `rate`
  (существующий сабмит уже добавляет `rate` в formData, mail.php
  конвертирует в эмодзи)
- Дефолтное значение datetime-local = текущее время клиента
- Валидация: без выбранной звезды не отправлять
- После успешной отправки: форма заменяется благодарностью (существующее
  поведение `.add-review`), при `rate >= 4` дополнительно показать
  `#add-review-good` (Яндекс/2ГИС)

### 7. `sass/components/_rate-employee.scss`

Стили страницы: заголовки блоков, размеры звёзд (5 шт крупнее, чем в
квизе 1–10), отступы. Подключить в `_components.sass`.

## Поток данных

Форма (`data-type="review"`) → POST `/mail.php` → валидация (`agree`,
`rate`) → Telegram (`tg_list.feedback`) + email (`emails`) + строка в
`gsheet_feedback` (лист gid=215559653). Поля с русскими именами проходят
в сообщения и таблицу без маппинга.

## Тестирование

Локально: `pnpm php`, http://127.0.0.1:5134/?qr_site=qr.aeroterms.ru,
затем `/?updatetable` — скачивание таблицы в
`storage/json/qr.aeroterms.ru-qr-employee.json`. Проверить:
- страница `/agadzhanyan-anastasiya` рендерит форму оценки
- редирект по `Code`
- отправка формы: оценка 5 → благодарность + внешние ссылки; оценка 2 →
  только благодарность; без звёзд — не отправляется
- остальные сайты (`?qr_site=qr.kia-samara.ru`) не затронуты

## Вне скоупа

Роутинг Code→URL, vcf, кнопки «Купить билет»/«Наши акции», правки
`sass/_fonts.sass` в рабочем дереве.
